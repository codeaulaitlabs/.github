## About

Code au Lait Labs builds its own software products and tools.

Projects can start from a practical problem, a new idea, or simply the feeling that something could work better than it does today.

The approach is simple: get something working, use it, see what needs to change, and improve it from there. Some ideas grow into full products. Others remain experiments or lead somewhere unexpected.
